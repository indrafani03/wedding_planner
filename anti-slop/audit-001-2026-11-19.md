# Audit UI/UX 001 (2026-11-19)

Mode: AFTER (audit). Belum ada perubahan kode. Pilih nomor yang mau diperbaiki.

Cara cek: `tsc --noEmit` dan `eslint` bersih. Dev server dijalankan, 12 halaman di-fetch dengan sesi tes: semua 200, `/nope` 404, tidak ada error server. Cek layout di browser (overflow, ukuran tap) **belum jalan** karena butuh PIN; temuan layout di bawah berasal dari baca kode.

## HIGH

1. **Open redirect di halaman PIN** (`src/proxy.ts:25-26`). `/masuk?next=//evil.example` saat sudah login langsung redirect ke `http://evil.example/` (terverifikasi dengan curl). `page.tsx` sudah memfilter `next`, tapi proxy jalan duluan dan tidak memfilter. Link phishing bisa memakai domain app ini.
2. **Tidak ada `error.tsx` / `loading.tsx` sama sekali** (R-27). Kalau Neon lambat (cold start) atau query gagal, user melihat layar diam lalu halaman error bawaan Next, tanpa tombol coba lagi dan tanpa bottom nav.
3. **"Hemat" di Budget Administrasi menyesatkan** (`src/app/budget-administrasi/page.tsx:27-29, 58`). Item yang harga real-nya belum diisi (0) dihitung sebagai penghematan penuh. Contoh: belum beli apa-apa, estimasi Rp10 jt, tampil "Hemat Rp10.000.000".
4. **Pencarian tamu tanpa debounce** (`src/app/tamu/guest-filters.tsx:51`). Tiap ketikan memicu `router.replace` + render server. Respons bisa datang tidak berurutan, jadi daftar bisa tidak cocok dengan teks di kotak cari.

## MEDIUM

5. **Tanggal default form Cash Flow pakai UTC** (`src/app/cashflow/entry-sheet.tsx:65`). Jam 00.00-07.00 WIB, default-nya tanggal kemarin.
6. **Countdown dan "lewat deadline" dihitung di zona waktu server** (`src/lib/format.ts:57-64`, dipanggil dari server component). Kalau di-deploy ke server UTC (mis. Vercel), "Hari ini!" dan status lewat deadline baru berganti jam 07.00 WIB.
7. **Nominal kosong / Rp0 tetap tersimpan** (`src/app/cashflow/actions.ts:26`). Catatan cash flow Rp0 masuk riwayat tanpa peringatan.
8. **Tap target di bawah 44px** (R-03): tombol kembali 32px (`src/components/page-header.tsx:25`), ikon Pengaturan 32px (`src/app/page.tsx:106`), Ubah/Hapus 32px tinggi (semua `*-sheet.tsx`, `delete-button.tsx:41`), checkbox 20px (`toggle-check.tsx:28`), toggle Hadir/Tidak/Belum sekitar 22px (`attendance-toggle.tsx:53`), filter tamu sekitar 28px (`guest-filters.tsx:86`). Hadir/Tidak/Belum letaknya rapat, jadi rawan salah pencet.
9. **Zoom dikunci** (`src/app/layout.tsx:26-28`, `maximumScale: 1, userScalable: false`). Pengguna dengan mata minus tidak bisa pinch-zoom (Android menurut, iOS mengabaikan). Zoom saat fokus input sudah dicegah oleh `font-size: 16px` di `globals.css:169-173`, jadi kunci ini tidak diperlukan.

## LOW

10. Toggle kehadiran dan filter tamu tidak punya `aria-pressed`; status hanya dibedakan lewat warna (R-32).
11. Bottom nav: di halaman yang dibuka dari Menu (Seserahan, Dokumen, Checklist, dll.) tidak ada tab yang aktif, jadi user kehilangan penanda posisi (`src/components/bottom-nav.tsx:47-54`).
12. Judul "Hasil (n) · CPP x / CPW y" di Tamu: n ikut filter, tapi x/y selalu total semua tamu (`src/app/tamu/page.tsx:104`).
13. `ProfileForm` tidak memakai `useActionToast`, jadi kalau sesi habis yang muncul hanya toast dan user tidak diarahkan ke layar PIN (`src/app/pengaturan/profile-form.tsx:38-40`).
14. `MoneyField`: kursor loncat ke akhir saat mengedit angka di tengah (`src/components/form/fields.tsx:119-124`).
15. Hidden input `invited` / `done` / `checked` di form edit diambil dari render terakhir. Kalau checkbox dicentang lalu form Ubah langsung disimpan sebelum refresh selesai, centangnya kembali seperti semula.
16. Total dibayar boleh melebihi Total Biaya; "Sisa" hanya jadi Rp0 tanpa peringatan (`src/features/budget/budget-screen.tsx:70`).
17. Kode grup dan nama grup Dokumen diisi bebas dan terpisah; salah ketik membuat grup baru (`src/app/dokumen/item-sheet.tsx:74-88`).
18. Lamaran dan Seserahan sama-sama memakai ikon `Gift` (`src/lib/nav.ts:38, 63`), jadi di grid modul keduanya sulit dibedakan.
19. Label tombol tutup sheet untuk pembaca layar masih "Close" (bahasa Inggris) (`src/components/ui/sheet.tsx:80`).

## Catatan antislop (non-bug)

- Belum ada `DESIGN.md` (R-37); tema rose/mauve di `globals.css` sudah berarah, tapi alasannya belum tertulis.
- Em dash hanya ada di komentar kode (`pin-pad.tsx:25`), bukan di teks UI. R-02 lolos.
- Tidak ada statistik palsu, testimoni, atau link mati di nav. Semua 10 tujuan menu merespons 200.
